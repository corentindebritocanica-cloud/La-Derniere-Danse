# La Dernière Danse

Cadeau des 2 ans : un roman imprimé, des artefacts d'époque en enveloppes, un site et un film d'animation.

## Où trouver quoi

| Emplacement | Contenu |
|---|---|
| `roman/La_Derniere_Danse.pdf` | **Le livre**, dernière version (84 pages A5, celle partie chez l'imprimeur). C'est la référence pour tout le reste. |
| `roman/la-derniere-danse.txt` | Le texte du livre extrait du PDF, pour retrouver rapidement un passage. |
| `PROJET.md` | Le carnet de projet : personnages, enveloppes, charte graphique, site, film, règles de cohérence. |
| `index.html`, `assets/` | Le site (galerie des personnages, débloquée par les mots de passe des enveloppes). |
| `film/` | Le film d'animation : plans animés (`film/plan-XX-….html`), fichiers communs (`film/lib/`), sources des plans (`film/src/`), storyboard. |

## Règles

- Le roman imprimé ne change plus. Le film et le site le suivent : avant de toucher à une scène, relire le chapitre dans `roman/`.
- Tout ce qui existe déjà sur les artefacts papier (plan de la glycine, carte du ciel, invitation, carnet de bal…) est repris tel quel.
- Aucun jeton d'accès ni mot de passe GitHub dans ce dépôt.

## Reprendre le travail dans une nouvelle conversation

- `film/INSTRUCTIONS.md` : mode d'emploi du film (état des plans, liens des artefacts, outils, règles, prochaines étapes). **À lire en premier.**
- `artefacts-papier/` : copie de tous les artefacts papier des enveloppes (sources + rendus PNG dans `artefacts-papier/png/`, catalogue dans `artefacts-papier/README.md`).
